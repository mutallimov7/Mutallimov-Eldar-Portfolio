## 📖 Overview

A clean, dark-themed personal portfolio website built with pure HTML, CSS, and JavaScript. Designed to present my projects, technical skills, education, and contact information in a modern and professional way.

---

## ✨ Features

- **Dark & Modern Design** — Dark navy background with glassmorphism cards and blue/green accents
- **Smooth Animations** — Fade-up entrance animations on scroll
- **Responsive Layout** — Mobile-friendly design
- **Interactive Navigation** — Fixed navbar with smooth scroll
- **CV Download** — One-click CV download button
- **All Sections** — Hero, Projects, Skills, Education, Languages, Contact

## 🚀 Getting Started

### View Locally

Simply open `index.html` in your browser — no build step required.

```bash
git clone https://github.com/mutallimov7/mutallimov7.github.io
cd mutallimov7.github.io
open index.html
```

### Deploy to GitHub Pages

1. Create a new repo named `mutallimov7.github.io`
2. Upload `index.html` and `cv.pdf`
3. Go to **Settings → Pages → Branch: main → Save**
4. Live at: `https://mutallimov7.github.io` ✅
